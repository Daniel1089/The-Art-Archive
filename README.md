# 🖼️ The Art Archive

The Art Archive is an iOS app created with the objective of using technology with the same purpose we once thought it would be used: learning. And, in order to do so, you will simply have to open the app, and you will find a new artwork waiting to be discovered! You will also have the ability to check any available artwork in the app thanks to the archive. In order to avoid any sort of "addictive model," I have not included any sort of streak or infinite view page, as it would only distract the user from the main objective, which is learning.
